Algerie 

Le système fiscal en Algérie n'est pas regroupé en un seul code unique, mais est régi par cinq codes principaux et un code de procédures :
Le Code des impôts directs et taxes assimilées (CIDTA)
Le Code des impôts indirects
Le Code des taxes sur le chiffre d'affaires (TVA, etc.)
Le Code de l'enregistrement
Le Code du timbre
Le Code des procédures fiscales (ajouté en 2002)

Angola : 

Structure of Angolan Tax LawThe General Tax Code (Código Geral Tributário)This is the procedural baseline. It does not list the specific tax rates or filing timelines for individual taxes. Instead, it defines the overall legal framework, general principles, taxpayer rights, audit processes, penalties, and anti-abuse rules.Substantive Individual Tax CodesEach major category of tax has its own dedicated legal text passed by the National Assembly. The primary active acts include:Corporate Income Tax Code (Código do Imposto Industrial): Governs corporate profits, currently at a base rate of 25%.Personal Income Tax Code (Código do IRPS): Governs individual and employment income.Value Added Tax Code (Código do IVA): Regulates consumption tax, sitting at a standard rate of 14%.Stamp Duty Code (Código do Imposto de Selo).Tax Benefits Code (Código de Benefícios Fiscais): Governs tax incentives and exemptions.
